Know the shape so you allocate prep correctly. For a ₹15–20L Bengaluru Tech Lead at a product/services company, expect **4–6 rounds**:

| # | Round | Duration | What is actually being scored |
|---|-------|----------|-------------------------------|
| 1 | Recruiter / HR screen | 20–30 min | Comp expectation, notice period, WFO willingness, communication, stability |
| 2 | Technical screen (DSA + language) | 45–60 min | Can you code cleanly under time; language fluency; edge cases |
| 3 | Machine coding / take-home (very common in India) | 90–120 min | Working code, OOP modelling, extensibility, README, tests |
| 4 | LLD / Design round | 45–60 min | Class design, SOLID, patterns, API contracts |
| 5 | HLD / System design | 60–75 min | Scale reasoning, trade-offs, data modelling, failure handling |
| 6 | Hiring manager / Leadership | 45–60 min | Ownership, conflict, mentoring, delivery, stakeholder mgmt, "why leaving" |
| 7 | Culture / Founder / CTO | 30 min | Motivation, longevity, values, salary close |

**Prep-time allocation for you specifically:** 25% System Design · 20% Leadership/Behavioral (your weakest signal, highest leverage at this title) · 15% DSA · 15% Backend fundamentals + DBMS · 10% LLD · 10% Resume deep-dive rehearsal · 5% Frontend/misc.

**The three sentences that decide the round before you speak:**
1. Your 90-second intro.
2. Your answer to "what's the most complex thing you've built?"
3. Your answer to "why are you leaving eLitmus?"
Scripted, rehearsed, timed. Nothing else in this document matters if these three are weak.
