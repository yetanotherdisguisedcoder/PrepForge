Go through **Ruby, Java, JavaScript, Python, C#, Rails, Node.js, Spring Boot, React, Django/Flask, .NET MVC, RSpec, Puppeteer, Prometheus, Grafana, MySQL, PostgreSQL, Redis, MongoDB, DynamoDB, Docker, Kubernetes, Kafka, CI/CD, Chef, Git, AWS**.

For each, mark: **Deep (can be grilled) / Working (can discuss) / Exposure (should be moved or removed)**.

⚠️ **Highest-risk entries:** **Kafka** (not mentioned in any bullet — if asked "tell me about a Kafka system you built" and you can't, it damages credibility on everything else), **MongoDB**, **DynamoDB**, **Django/Flask**. Either build a small proof this month or restructure the skills section into tiers: *Expert · Proficient · Familiar*. Tiering is honest and reads as mature.
