**They will ask:**
- What does the agent actually do, and what's the failure mode when it gets it wrong? Invoicing errors are expensive.
- What's the human approval step?
- How do you audit an AI-generated invoice?
- Reconciliation between agent output and ground truth?
- Why an agent rather than deterministic code? (**Be careful — "we used AI" for a task that deterministic code solves better is a red flag to some interviewers. Have the justification: unstructured input, variable formats, exception handling.**)
