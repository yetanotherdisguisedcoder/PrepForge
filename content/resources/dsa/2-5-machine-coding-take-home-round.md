Typical prompts: Parking Lot, Splitwise, Elevator, Snake & Ladders, Cab Booking, Rate Limiter, In-Memory KV Store, Logging Framework, Cache with eviction policies, Tic-Tac-Toe, Library Management, Vending Machine, ATM, BookMyShow seat booking, Notification Service.
- [ ] Practice building one end-to-end in 90 min: clean packages, interfaces, DI, no framework needed
- [ ] Always include: README (assumptions, how to run, design decisions, what you'd do with more time), unit tests, a `main`/driver
- [ ] Show extensibility explicitly (e.g. eviction policy as a strategy interface)
- [ ] Thread-safety discussion even if single-threaded implementation
- [ ] No god classes, no static state, no hardcoded strings
